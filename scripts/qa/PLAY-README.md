# DeskTown 디자인·행동·음향 적용 MVP

ZIP을 빈 폴더에 전부 압축 해제하고 **Start-Play.cmd**를 더블클릭하세요. 편집기나 .NET SDK는 필요 없습니다. 다른 DeskTown이 실행 중이면 먼저 종료하세요.

## 처음부터 플레이

1. 안내 화면에서 Continue → Town의 Focus 버튼을 누릅니다.
2. 25분, Any App, PiP Companion을 선택하고 Start Focus를 누릅니다.
3. 작은 Mina 창을 보며 다른 앱에서 작업합니다. 상단 드래그로 이동하고 −/+로 크기를 바꿀 수 있습니다.
4. 트레이 메뉴에서 표시 모드 전환·End Focus·Open DeskTown을 사용할 수 있습니다.
5. Focus 누적 25분으로 Workshop이 완성되면 트레이에서 Town을 열어 완성 연출과 지도 발견을 확인합니다.
6. 종료는 트레이의 Quit입니다. 같은 Start-Play 버튼으로 다음에 저장을 이어갑니다.

이 게임은 집중 시간으로 마을을 복구하는 초기 MVP입니다. 캐릭터를 직접 조작하는 이동 게임은 아닙니다. 유휴·잠금·절전 시간은 집중 누적에서 제외되므로 실제 작업과 함께 사용하세요.

## 완성 연출부터 빠르게 보기

**Start-Quick-Look.cmd**는 완성 직전의 별도 데모로 시작합니다. Workshop 완성 → Old Railway Map 발견까지 바로 볼 수 있습니다. 실행마다 새 복사본을 쓰므로 플레이 진행에는 영향을 주지 않습니다. 화면 전체 비교는 `art-preview/review.html`에서 볼 수 있습니다.

## 이번 빌드 범위

- Workshop 완성·지도 확인 후 **Focus with Mina**로 25/45/60분 세션을 반복할 수 있습니다. 일일·총 집중 기록은 이어지고 Workshop과 완료·지도 보상은 다시 지급되지 않습니다.
- **Start-Daily-Focus.cmd**는 복구가 끝난 별도 데모에서 바로 시작하고 `qa-sessions/daily`에 진행을 유지합니다. 처음부터 플레이하는 `play` 저장과 분리됩니다. Railway는 후속 빌드 예고입니다.
- `daily-preview/review.html`에서 새 Town·설정·두 번째 세션 후의 실제 렌더를 볼 수 있습니다. 설정 패널은 캐릭터보다 앞에 표시됩니다.
- Noah는 독서·산책·모닥불 곁 휴식을, Rumi는 Library·Workshop 주변 탐색을 서로 다른 동선과 리듬으로 보여줍니다.
- Mina는 집 앞을 걷고, 작업 중 짧은 살펴보기·스트레칭 후 작업을 이어갑니다. Walk 뒤 Work가 이어지고 그림자도 함께 움직입니다.
- 새 행동 미리보기는 `behavior-preview/review.html`입니다. 화면을 숨기면 일상 행동 시간이 멈추며 Reduced motion에서 선택적 이동·스트레칭이 꺼집니다.
- 승인된 시각 아트 38개와 Town·Mina·NPC·효과·로고·아이콘·지도 적용.
- PiP: 작은 창만 표시. Minimized: Town 작업 표시줄 항목 유지. Hidden: 트레이만 유지.
- Focus 완료 시 PiP가 사라지고 트레이에서 완료 상태를 확인할 수 있습니다.
- Reduced motion은 트레이에서 설정하며 재실행 후 유지됩니다.
- 승인된 음향 8개가 연결됐습니다. 마을 주변음·새·발소리, 작업대 망치, 버튼·완성·지도 발견 신호가 재생됩니다.
- 트레이의 **Audio** 체크를 끄면 모든 소리가 멈춥니다. 설정은 저장됩니다. 기존 Audio=false 저장은 계속 무음이며 새 게임의 기본값은 켜짐입니다.
- 숨긴 화면·최소화·Windows 잠금 중 소리는 정지하고, 재열기에서 지난 소리를 몰아서 재생하지 않습니다. 완료·발견 신호는 해당 연출 화면을 볼 때 재생합니다.
- `audio-preview/review.html`에서 개별 음원과 믹스 후보를 비교할 수 있습니다. 실제 게임에서는 보행·타격 프레임과 화면 상태를 따릅니다.
- Ghost Focus는 검증 대기라 비활성입니다.

개인 저장과 분리된 `qa-sessions/play/save.json`에 저장합니다. 이전 QA의 `focus` 세션과도 분리됩니다. 다른 폴더로 옮길 때 진행을 이어가려면 이 세션 폴더를 함께 보관하세요. 스크립트는 실행 정책을 변경하지 않습니다. 실행이 차단되면 오류와 해당 환경의 허용 절차를 확인하세요.
