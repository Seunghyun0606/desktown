## QA-PIP-001

- 상태: 수정 완료·사용자 재확인 대기. 아트 완성 후 플레이 MVP 준비 지시에 따라 처리했다.
- 심각도: P1(원치 않는 작업 창 표시).
- 관측: PiP 중 Companion과 기존 Town 메인 창이 동시에 나타나는 경우가 있음.
- 기대: PiP Companion만 표시, Town 창과 작업 표시줄 항목은 숨김.
- 대상: 직전 전달한 QA 빌드 `4ba5a2ee`로 추정. 사용자가 실제 실행 SHA·전환 순서를 별도로 제공하지는 않음.
- 수정 전 확인: Focus 시작, Minimized/Hidden에서 PiP 전환, 트레이 Open 이후 각각 재현 여부와 창 상태 확인.
- 완료 조건: 내보낸 Windows 앱에서 각 경로의 PiP 단일 창 표시 확인, 세션·저장 유지, Minimized/Hidden 회귀 검사.

사용자의 전체 확인 보고를 기록하며, 제공되지 않은 DPI·모니터·앱 입력 조합을 임의로 Pass 처리하지 않는다. 개인 저장이나 업무 화면은 수집하지 않았다.

## 아트 완성 후 MVP 후속

- 기존 코드의 `Window.Visible = false`는 Godot 루트 창을 숨기지 못했다. 실제 Windows 내보내기에서 PiP 시작 후 Town이 최소화되지 않는 실패를 재현했다.
- Godot 공식 앱 지침대로 루트 창을 최소화하고 `Unfocusable`로 작업 표시줄·Alt-Tab 제외 정책을 적용했다. Minimized와 명시적 Open에서는 이를 해제한다. PiP를 띄우기 전에 Town을 처리한다.
- 분리된 실제 Windows 내보내기에서 26개 창 상태 검사가 통과했다. 모드 반복 전환, 트레이 Open/복귀, 4배율, PiP 닫기, 세 모드 종료, 최대화 복원을 검사했다. 같은 Focus 세션 유지도 확인했다.
- Win32 `IsIconic`/`IsWindowVisible`/`WS_EX_NOACTIVATE` 확인이며 실제 사용자의 작업 표시줄·Alt-Tab·타이핑·다중 모니터 조작 합격을 대신하지 않는다.
- 최종 시각 38개와 플레이 시작·빠른 연출 미리보기 런처를 담은 MVP는 [플레이 안내](../../scripts/qa/PLAY-README.md)를 따른다.
