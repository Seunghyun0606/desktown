# Reward 완성 연출 색·효과 테스트 — 2026-10-11

## 현재 판정

사용자가 House·길·식생 환경 스타일을 승인하고 완성 연출 색·효과 테스트 진행을 선택했다. 아트 지침의 다섯 번째 게이트인 **Reward 색·효과 프레임**을 준비했다. [검토 페이지](review.html)에서 네 정지 프레임, 최근접 1×/2×/3×, 흑백, 효과 없는 완성 상태를 비교한다. Reward 스타일의 사용자 승인은 대기 중이다.

최종 대상은 `prepared-v2/`다. 연기 시작점을 굴뚝에 정렬하기 전 결과는 무시되는 `build/reward-intermediate-20261011/`에 보존했다. 승인된 건물·환경·Mina PNG를 합성 입력으로 사용했다. 게임 장면·설정·저장·카탈로그를 바꾸지 않았다.

## 생성 출처

내장 `image_gen.imagegen`으로 연기와 반짝임을 **각각 별도 생성**했다. 승인된 [환경 클러스터 2×](../town-cluster-v1/prepared-v3/cluster-2x.png)는 재료·빛·색 계열의 참고다. 투명 배경과 작은 단일 효과를 요청했으며 외부 이미지·에셋 팩을 사용하지 않았다.

| 대표 효과 | 보존한 AI 원본 | 실제 출력 크기 | 요청 기록 |
| --- | --- | --- | --- |
| 연기 | [smoke.png](sources/smoke.png) | 1297×1212 RGBA | [프롬프트](sources/smoke-prompt.txt) |
| 반짝임 | [spark.png](sources/spark.png) | 1536×1024 RGBA | [프롬프트](sources/spark-prompt.txt) |

원본은 `.codex/generated_images/01a0e389-e95e-7dc0-8907-5b4fb12a6f3c/`에서 복사했다. 연기는 `exec-94ab5b01-53e8-4760-81c1-3656a83746e9.png`, 반짝임은 `exec-b300f0a2-8fc8-42cb-9c74-1ea01cbbc32c.png`다. 원본을 수정하지 않았고 SHA-256을 [변환 기록](prepared-v2/preparation.json)에 보존했다. 이는 AI 출처 기록이며 제작용 납품·라이선스 승인을 대신하지 않는다. 이미지 도구 자체가 32×32/16×16을 출력했다고 기록하지 않는다.

## 픽셀 변환과 구성

사용자가 앞서 허용한 Python 변환·픽셀 규격 정리로 [prepare_reward_review.py](../../../../../scripts/assets/prepare_reward_review.py)를 실행했다.

- **연기:** 알파 128 이상 영역을 잘라 최근접 23×28로 맞춰 32×32 셀의 `(5,4)`에 놓았다. 4색의 따뜻한 회색·크림 계열로 제한했다. 밑줄의 시작 픽셀 x=6/7을 기준으로 클러스터의 굴뚝 앵커 `(316,63)` 바로 위에 놓았다. 효과 셀 원점은 `(310,31)`이다. 이 앵커는 검토 클러스터용이며 런타임 피벗 확정이 아니다.
- **반짝임:** 원본에는 요청과 달리 부드러운 빛 번짐이 있었다. 알파 128 임계값으로 주변 저알파 번짐을 제외하고 최근접 11×11로 맞춰 16×16 셀의 `(3,5)`에 놓았다. 최대 3색 양자화 요청의 실제 결과는 **2색**이다. 알파 0/255, 투명 RGB 0으로 정리했으며 흐림·보간·발광 필터를 추가하지 않았다.
- **합성:** 기존 384×288 클러스터의 건물·Mina·길·덤불 원점을 유지했다. 반짝임은 `(229,106)`, `(281,98)`의 작은 셀 두 곳에만 있다. 연기는 위 굴뚝에만 있으며 전면 섬광·전체 색 변환은 없다. Mina는 승인된 중립 프레임이다.
- **색:** 기존 Mina·Workshop·환경의 서로 다른 후보 팔레트를 그대로 사용했다. 효과의 작은 색 램프는 Art Bible에서 허용한 범위의 제안이며 프로젝트 전체 24–32색 팔레트 확정은 아니다.

| 프레임 | 보여 주는 방향 | 범위 |
| --- | --- | --- |
| [Before](prepared-v2/before-1x.png) | 불규칙한 지붕·어두운 창·연기 없음 | Broken 대비 참조. 실제 연출 직전의 Repairing 아트는 미제작 |
| [Beat](prepared-v2/beat-1x.png) | 깨끗한 지붕·따뜻한 창·반짝임 둘·굴뚝 연기 | 한 효과 비트의 정지 프레임, 지속 시간은 미검증 |
| [Calm](prepared-v2/calm-1x.png) | 반짝임 제거·작은 연기만 | 차분한 완성 상태, 연기 루프는 미제작 |
| [Reduced](prepared-v2/reduced-1x.png) | 효과 제거·건물 자체로 완성 전달 | 승인된 환경 클러스터와 픽셀 동일, 완성 카드 문구·색 별도 제안 |

HTML의 `Workshop restored / 집중한 시간이 마을에 남았습니다.` 카드는 문구·따뜻한 종이색 배치 제안이다. 카메라·사운드·시간·Skip 버튼 또는 제품 설정 변경을 포함하지 않는다.

## 현재 구현과 후속 항목

[UX Flow H](../../../../design/UX_FLOW.md)의 의도는 마지막 Work 두 번 → 잠깐 정적 → 반짝임·소리·건물 교체·연기·창빛 → Celebrate → 카드다. 현재 `RewardReveal.cs`는 텍스트와 2초 대기 후 건물 변경 이벤트, Continue를 제공하며 동작 줄이기에서는 0.1초 후 종료한다. 이 자료가 해당 타임라인·실제 창 입력·Windows QA를 구현하거나 검증한 것은 아니다.

FX-SMK-001은 32×32 **4프레임/4FPS**, FX-SPK-001은 16×16 **4프레임/8FPS** 계약이다. 이번 파일은 각각 **대표 1프레임**이므로 납품 시트로 배정하지 않는다. Repairing, Mina Celebrate와 마지막 Work 배치, 효과 시트·음향·카메라·동작 줄이기의 실행 중 연결 및 전체 팔레트 검토가 남는다. 이후 제작 준비는 이 스타일 승인과 별도 진행한다.

## 검증

RGBA8/sRGB, 크기, 알파 0/255, 투명 RGB 0, 효과 색 수, 최근접 확대의 픽셀 복제, 입력 SHA-256 보존을 검사했다. 효과 비트의 차이가 선언한 연기·반짝임 셀 안에만 있는지, 효과 없는 완성 프레임이 승인된 환경 클러스터와 같은지도 검사했다. 별도 출력 폴더로 재생성한 **24개 파일 전체가 바이트 일치**했다.

카탈로그 검증: **46 ID / 0 배정**, 기존 에셋 계약 단위 테스트 **3개 통과**. Chrome에서 1×·흑백·효과 없는 프레임·완성 카드 표시 및 모든 HTML 이미지 로드를 확인했고 콘솔 오류는 없었다. 확대 프레임·효과 셀·비교 보드를 눈으로 확인했다. 스타일의 사용자 승인은 아직 필요하다.

## 재현

Pillow 12.3.0을 사용하는 저장소의 무시되는 가상환경을 사용했다. 출력은 새 폴더여야 한다.

```powershell
.\build\tools\art-python\Scripts\python.exe scripts/assets/prepare_reward_review.py `
  docs/art/reviews/2026-10-11/reward-v1/sources `
  docs/art/reviews/2026-10-11 build/reward-check
```

각 프레임 및 효과에 1×/2×/3× PNG, 프레임별 흑백 PNG, [네 프레임 비교 보드](prepared-v2/comparison-board.png), [검사 기록](prepared-v2/preparation.json)을 포함한다. HTML은 파일로 직접 열거나 저장소 루트의 `python -m http.server 8765 --bind 127.0.0.1`로 제공할 수 있다.
