## 전체 접촉 비교

[비교 보드](prepared-v1/comparison-board.png), 클립/배치별 20개 장면 PNG, 4개 접촉 시트와 4개 APNG를 준비했다. APNG는 Work 6 FPS에 가까운 167ms/프레임, Rest 2 FPS의 500ms/프레임으로 반복한다. HTML은 계약 FPS로 재생한다.

새 바닥의 여백 때문에 실제 아트를 넣은 참조의 첫 행이 y=148이다. 이전 기하학적 바닥은 y=154였다. 발 마지막 행 y=147 뒤의 6개 빈 행을 **아트 여백으로** 줄이며 Floor 노드를 옮기지 않았다. 실제 게임 카탈로그는 미배정이므로 현재 실행 게임의 바닥은 아직 기존 플레이스홀더다.

배치안의 작업대·의자·그림자는 Work와 Rest 전체에서 같은 위치다. Mina를 순간 이동시키거나 캐릭터 피벗/프레임을 바꾸지 않았다. 그림자·소품 뒤에 Mina를 그려 의자가 다리를 앞에서 가리지 않게 했다. 현재 램프 바인더 (281.5,26)는 정지 참조에서 (282,26)로 반올림했다. 반 픽셀을 사용한 실제 바인더 처리는 별도 Godot 검토 대상이다.

Work에는 망치가 이미 들어 있어 별도 도구를 추가하지 않았다. 프레임 4는 예상 접촉 후보이며 확정한 `tool_contact` 이벤트가 아니다. 모든 프레임에서 도구를 볼 수 있지만 현재 작업대와의 간격, 배치안 상판 접촉, Rest의 엉덩이 지지·다리 겹침, Work 중 의자 가림은 사용자가 판정할 시각 항목이다. 자동 검사는 자연스러운 자세나 완벽한 접촉을 증명하지 않는다.
