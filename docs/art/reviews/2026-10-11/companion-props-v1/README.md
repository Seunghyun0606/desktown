- 외부 원본은 `C:/Users/limse/.codex/generated_images/01a0e389-e95e-7dc0-8907-5b4fb12a6f3c/`에 그대로 남겼다. 작업대 `exec-159745c0-c253-41ef-8f6d-429657b3cf1f.png`, 램프 `exec-358d5621-4264-4a2e-8ab6-f1cc63188910.png`, 창 `exec-7a3905b1-9be2-40a6-87fb-979ec09d3f9f.png`, 도구 `exec-3d1b5161-cee1-49de-b0b9-4eff0183bc38.png`에서 저장소로 복사했다.
- 사용자에게 허용받은 Python 변환·픽셀 정리 방식으로 [prepare_companion_props.py](../../../../../scripts/assets/prepare_companion_props.py)를 실행했다. 2셀 원본은 가로 절반씩 나누고, 알파 128 기준으로 0/255 및 투명 RGB 0으로 정리했다. R/G/B 가중치 2/4/3으로 승인 32색에 대응했다. 효과 색은 섞지 않았다.
- 정리한 각 원본 셀의 불투명 경계를 최근접 축소하여 선언한 영역에 맞췄다. 작업대 `(4,43)-(92,64)`, 램프 `(7,18)-(25,48)`, 창 `(15,29)-(81,80)`, 도구 `(7,5)-(25,27)`. 캔버스와 투명 여백을 규격에 맞췄으며 원본 확대 크기를 실제 픽셀 규격으로 표기하지 않는다.
- 램프 ON은 OFF의 알파와 픽셀 위치를 유지하고, 두 이미지에서 겹치는 불투명 위치에만 생성된 ON 색을 가져왔다. 최근접 축소에서 끊긴 가는 줄은 OFF의 x=16, y=20..33에서 **투명 픽셀만** `#a36f45`로 이어 주었으며 ON에도 같은 줄을 유지했다. 광원을 소품 밖으로 번지게 하지 않았다.
- 입력 SHA-256, 원본 셀·불투명 경계, 대응 영역, 색 수, 피벗, 출력 해시는 [preparation.json](prepared-v1/preparation.json)에 기록했다. AI 생성 출처 기록은 최종 출처·납품 승인을 대신하지 않는다.

## 배치 참조와 남은 접촉 검토

360×200 Companion을 PNG/Canvas로 재현했다. 배경·헤더·바닥·의자·식물은 기하학적 참조이며 실제 Godot 실행 캡처가 아니다. 아래 좌표는 네이티브 PNG의 왼쪽 위 원점이다.

| 항목 | 현재 배치 참조 | 미적용 접촉 비교안 |
| --- | --- | --- |
| Mina Work 프레임 4 | (100,103) | 동일 |
| 작업대 | (151,91), 상판 첫 행 y=134 | (135,91), 16px 왼쪽 |
| 바닥 첫 행 | y=154 | y=148 |
| 창 | (119,10), 그림은 y=39부터 | 동일 |
| 램프 | 바인더 (281.5,26), PNG는 (282,26) | 동일한 PNG 원점 |

현재 Mina 발 마지막 행은 y=147이므로 바닥 전 6행이 비어 있다. 비교안은 이 공간을 줄이고 작업대를 예상 도구 접점 (139,134)으로 옮긴 **참조 제안**이다. 그 점은 확정된 접촉 픽셀이나 런타임 이벤트가 아니다. 모든 Work 프레임과 Rest·의자의 정렬, 피벗, 바닥·그림자 및 반 픽셀 바인더 처리는 후속 검토 대상이다. 기존 Mina Work에 망치가 들어 있어 별도 도구를 Mina 위에 덧그리지 않았다. 도구 분리 방식과 프레임 의미를 실제 구현하기 전 결정해야 한다.

[비교 보드](prepared-v1/comparison-board.png)는 네 소품의 컬러·흑백 2×, 현재/제안 1× 및 접촉 부분 4×를 제공한다. 소품 외형 승인과 실제 배치·도구 분리 구현 승인은 별도다. 게임의 장면·진행·저장·창 입력 코드 및 런타임 카탈로그는 변경하지 않았다.

## 검사 결과

- 4개 시트의 크기·셀 수와 6개 개별 프레임이 매니페스트와 일치한다. 시트의 각 셀은 개별 PNG와 동일하다.
- 기본 프레임은 RGBA8/sRGB, 알파 0/255, 투명 RGB 0이며 승인 32색의 부분집합이다. 흑백·기하학적 장면 참조는 색 규격 검사용 기본 아트가 아니다.
- 램프 두 상태의 알파가 동일하고 색은 서로 다르다. 가는 줄 연결, 도구 두 자세 구분, 모든 2×/3× 확대 픽셀의 최근접 복제를 별도로 검사했다.
- 독립 폴더에 재생성한 33개 PNG와 변환 JSON, 총 **34개 출력이 바이트 단위로 일치**했다. 원본·프롬프트·팔레트·Mina 입력 해시를 확인했다.
- Chrome에서 1× 흑백·램프 ON·기울인 도구·좌우 반전·접점 표시, 3× 컬러·밝은 배경, 2× 기본 보기로 전환했다. 이미지 로드 실패나 페이지 콘솔 오류가 없었다.
- 카탈로그 검증과 기존 3개 테스트가 통과했다. 46개 런타임 항목은 모두 미배정이다. Windows 네이티브 창·입력/DPI 검증은 이 검사로 통과시키지 않았다.
