# 공통 팔레트 24색·32색 비교 — 2026-10-11

## 현재 판정

사용자가 Reward 완성 연출의 색·효과 방향을 승인하고 공통 팔레트 비교 진행을 선택했다. [검토 페이지](review.html)에서 승인된 원본과 공통 **24색 / 32색** 후보를 비교한다. 최종 후보 선택은 대기 중이다. 기존 스타일 원본·카탈로그·게임·저장 데이터는 변경하지 않았다.

**32색 후보를 권장한다.** 두 후보 중 Mina 모자·얼굴 및 건물 세부의 원래 RGB 값을 더 가깝게 유지한다. 24색은 더 작은 기본 색 집합이다. 잔디의 RGB 차이는 24색 쪽이 약간 작으므로 32색이 모든 종류에서 수치상 우수하다고 표기하지 않는다. RGB 차이나 동일한 실루엣 검사는 시각 품질의 사용자 승인을 대신하지 않는다.

## 입력과 변환

새 AI 이미지를 생성하지 않았다. 사용자가 앞서 승인한 Python 변환·픽셀 정리 방식으로 기존 PNG의 색만 변환했다. 입력은 이 날짜의 다음 승인된 검토 자료다.

- Mina 중립 48×48, Idle 192×48 / 4프레임, Work 288×48 / 6프레임.
- Workshop Broken·Complete 각 160×128.
- House 128×128, 잔디·길·덤불 각 32×32.
- Reward 연기 32×32와 반짝임 16×16 대표 셀. 이 둘은 **별도 효과 색 램프**로 그대로 유지한다.

입력 9종의 기본 색 합집합은 **95색**, 연기·반짝임의 합집합은 **6색**이다. [변환 기록](prepared-v2/preparation.json)에 입력 경로·SHA-256·종류별 원본 색→후보 색 매핑을 저장했다. 입력 PNG를 수정하지 않았다. 기존 AI 출처·프롬프트·정리 기록은 각 원본 검토 폴더에 있다.

[prepare_palette_review.py](../../../../../scripts/assets/prepare_palette_review.py)의 방법:

1. 기본 아트 9종에 각각 같은 4096픽셀 표본 예산을 준다. 각 PNG 안의 불투명 색 빈도에 비례해 개수를 배분하며, 나머지는 큰 소수부 순서·RGB 순서로 결정한다. 큰 건물·반복 잔디·긴 시트의 면적만으로 색이 결정되지 않게 했다. Neutral·Idle·Work는 각각 하나의 종류다.
2. Pillow median cut으로 표본에서 24색 또는 32색을 고른다. 디더링하지 않는다.
3. 모든 기본 아트에 **하나의 같은 색 집합**을 적용한다. RGB 거리의 가중치는 R=2/G=4/B=3이며 같은 거리의 경우 RGB 순서를 사용한다. 이는 재현 가능한 비교 방법이며 지각적 색 최적화나 수작업 명암 조정을 뜻하지 않는다.
4. 위치·크기·알파·실루엣·프레임 순서는 유지한다. 새 픽셀을 그리거나 윤곽을 정리하지 않았고 효과의 색도 변환하지 않았다.

최종 폴더는 `prepared-v2/`다. 색상표와 개별 팔레트 JSON을 넣기 전 결과는 무시되는 `build/palette-intermediate-20261011/`에 보존했다.

## 출력과 비교

| 항목 | 원본 | 공통 24색 | 공통 32색 |
| --- | --- | --- | --- |
| 기본 아트 합집합 | 95색 | 24색 | 32색 |
| 별도 효과 램프 | 6색 | 기존 6색 유지 | 기존 6색 유지 |
| Mina 중립 RGB RMS | — | 6.585 | 4.722 |
| Mina Work RGB RMS | — | 6.634 | 4.891 |
| Workshop Complete RGB RMS | — | 8.032 | 6.785 |
| 잔디 RGB RMS | — | 1.275 | 1.548 |

RMS는 원본 대비 채널별 색 차이의 제곱평균제곱근이다. 낮을수록 수치가 가깝지만 가독성·품질 점수는 아니다. 색 수는 기본 아트만의 값이며 실제 효과 포함 장면은 더 많은 색을 사용한다. 배경 비교 보드의 흰색·회색·어두운 색과 알파 합성 결과도 기본 팔레트 색 수에 포함하지 않는다.

- [원본/24색/32색 비교 보드](prepared-v2/comparison-board.png).
- [24색 색상표](prepared-v2/shared24/swatches.png), [24색 JSON](prepared-v2/shared24/palette.json).
- [32색 색상표](prepared-v2/shared32/swatches.png), [32색 JSON](prepared-v2/shared32/palette.json).
- 각 방식에 기본 아트 9종의 원래 크기 PNG, Reward 4프레임의 1×/2×/3× PNG, Mina의 배경·불투명도 비교 보드를 포함했다.
- HTML은 원본/후보 나란히 보기, 후보 선택, Reward 상태, 최근접 배율, 흑백, Mina 시트 배경을 제공한다.

Mina 배경 보드는 2× 최근접 확대이고 위는 100%, 아래는 40% 알파다. 왼쪽부터 흰색·회색·어두운 배경이다. 원래 크기 RGBA의 불투명 픽셀을 102/255 알파로 합성해 40% 표시를 비교했다. 실제 Ghost 창·사용자 작업 화면·포인터 통과 검증이 아니다.

## 검증과 한계

크기·알파 마스크·투명 RGB 0·sRGB·공통 색 집합·순수 검정 기본색 없음·입력 해시 보존을 검사했다. 원본 방식으로 재합성한 Reward 네 프레임은 승인된 Reward PNG와 픽셀이 같다. Idle 4 / Work 6프레임은 색 변환 후에도 각각 구분되며 발 접점과 실루엣은 알파 마스크가 동일해 유지된다. 별도 출력으로 재생성한 **72개 파일 전체가 바이트 일치**했다.

에셋 카탈로그는 **46 ID / 0 배정**, 기존 계약 테스트 **3개 통과**다. 브라우저에서 24색·32색 선택, 1×·흑백·Broken 비교·어두운 시트 배경, 24/32개 색상표와 Canvas 크기를 확인했고 PNG/JSON 및 콘솔 오류는 없었다.

픽셀 형태는 유지되지만 가까운 명암 색의 합병으로 세부가 덜 읽힐 수 있다. 40% 표시는 배경에 따라 약하며 실제 Ghost 가독성·입력 QA가 필요하다. 수작업 얼굴·망치 명암 조정, Companion 도구/바닥 정렬, 제작 전 Repairing·Walk·Rest·Stretch·Celebrate와 남은 아트는 여전히 필요하다. 선택된 후보는 **현재 제작 준비의 공통 색 기준**이다. 신규 아트에 따라 색 변경이 필요하면 별도 검토한다. 이번에 Art Bible의 최종 색 또는 런타임 배정을 확정하지 않았다.

## 재현

Pillow 12.3.0의 저장소 내 무시되는 가상환경을 사용한다. 출력은 새 폴더여야 한다.

```powershell
.\build\tools\art-python\Scripts\python.exe scripts/assets/prepare_palette_review.py `
  docs/art/reviews/2026-10-11 build/palette-check
```

HTML은 PNG 외에 검사 JSON을 읽으므로 로컬 HTTP로 연다. 저장소 루트의 `python -m http.server 8765 --bind 127.0.0.1` 후 `http://127.0.0.1:8765/docs/art/reviews/2026-10-11/palette-v1/review.html`을 사용한다.
