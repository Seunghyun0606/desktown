실제 장면의 배치안

Godot GPU 캡처입니다. 75/100/125/150%는 SubViewport 배율 비교이며 네이티브 Windows DPI 검사가 아닙니다. 마을은 완료 상태, Companion은 Mina의 승인된 Work 접촉 프레임/Rest 첫 프레임을 고정하고 효과 위상만 바꿉니다.

위상 비교 재생은 4개 정지 캡처를 순서대로 보여줍니다. 각 효과의 원래 FPS는 아래 개별 셀에서 확인합니다. Spark는 접촉 시 한 번만 재생하는 제안이며 지속적인 반짝임이 아닙니다.

  • Workshop 연기는 굴뚝에서 왼쪽 위로 흘려 Library 가림을 피합니다. 모닥불은 기존 주황 박스를 대체하고 풀 흔들림은 두 작은 지점에만 둡니다.
  • 장식은 기존 Plant 위치에 배정합니다. 별도 망치는 작업대 오른쪽 정지 소품으로 두며 Mina 손의 기존 망치와 중복 부착하지 않습니다.
  • Reduced motion 제안은 연기·풀·반짝임·김을 숨기고 모닥불은 첫 프레임에 고정합니다. 실제 설정·타이밍 연결은 아직입니다.
  • 로고·지도·Focus 아이콘을 기존 화면에 배치하고 글을 가리지 않도록 불투명한 따뜻한 어두운 패널을 제안합니다. 지도 패널은 높이를 늘렸고 버튼·문구·게임 상태는 유지합니다.
