# DeskTown v0.1 승인 팔레트

사용자는 2026-10-11 공통 팔레트 비교의 **A: 32색 승인 — 제작 기준으로 사용**을 선택했다. 이 폴더가 이후 아트 제작의 색 값 기준이다.

| 기준 | 파일 | 용도 |
| --- | --- | --- |
| 기본 32색 + 별도 효과 6색 | [desktown-v01-32.json](desktown-v01-32.json) | 정확한 RGB/HEX, 승인 날짜, 비교 원본 SHA-256 |
| 기본 32색 | [desktown-v01-32.gpl](desktown-v01-32.gpl) | GPL 팔레트를 지원하는 픽셀 편집기의 기본 색 |
| 효과 6색 | [desktown-v01-effects-6.gpl](desktown-v01-effects-6.gpl) | 연기·반짝임에 사용하는 별도 색 램프 |
| 색상표 | [승인된 32색 PNG](../reviews/2026-10-11/palette-v1/prepared-v2/shared32/swatches.png) | 색 값과 화면 표시 비교 |

기본 팔레트는 [비교 결과의 shared32](../reviews/2026-10-11/palette-v1/prepared-v2/shared32/palette.json)와 **정확히 같은 32색**이다. 효과 6색은 승인된 Reward 연기·반짝임의 색을 유지한다. GPL의 C01 등의 이름은 각 파일의 색 번호이며 게임 에셋 ID나 재료 의미를 정의하지 않는다.

## 적용 범위

- 캐릭터·건물·환경의 새 제작 아트에는 기본 32색을 사용한다. 대표 연기·반짝임의 효과 6색은 별도로 유지한다.
- 이미 승인된 비교의 PNG와 원본·프롬프트·변환 기록은 보존한다. `shared32/`의 색을 맞춘 아트는 제작 준비 입력으로 사용할 수 있다.
- 색 선택은 아트 제작의 기준 승인이다. 개별 시트의 동작·도구 가독성·피벗·전체 변형·출처 검증이나 런타임 카탈로그 배정을 대신하지 않는다.
- 새 아트를 위해 색 변경이 필요하면 이 기준을 조용히 교체하지 않고 변경안을 비교해 사용자 검토를 받는다. 현재 JSON/GPL은 게임이 읽는 설정·저장 스키마가 아니다.
